# pa-cwl Testing Guide

## Overview

pa-cwl includes 36 integration tests across 16 workflows. Tests use small
simulated datasets (primarily yeast-based) to validate CWL workflow logic,
tool wiring, and conditional step behavior. Tests are run with
[cwltool](https://github.com/common-workflow-language/cwltool) locally.

## Running Tests

```bash
# Run a single test
cd workflows/<pipeline>
cwltool main.cwl tests/<test-file>.yaml

# Run with Docker (recommended)
cwltool --singularity main.cwl tests/<test-file>.yaml
# or
cwltool main.cwl tests/<test-file>.yaml  # uses DockerRequirement hints
```

## Test Data

All test data lives under `test-data/` with the following structure:

| Directory | Contents | Used by |
|-----------|----------|---------|
| `yeast/` | S. cerevisiae genome, GTF, simulated PE reads, Bowtie2 index, scRNA-seq reads, tumor reads, known sites VCF, barcode whitelist, intervals BED | sarek, raredisease, rnaseq, methylseq, atacseq, chipseq, cutandrun, scrnaseq |
| `nanopore/` | Simulated nanopore reads, reference FASTA | nanoseq |
| `metagenome/` | Simulated metagenomic PE reads | mag |
| `viral/` | Simulated viral amplicon reads, reference FASTA, primer BED | viralrecon |
| `hic/` | Simulated Hi-C PE reads, reference, Bowtie2 index, chromsizes | hic |
| `amplicon/` | 16S amplicon PE reads, taxonomy reference | ampliseq |
| `fusion/` | Simulated fusion reads, reference, GTF, STAR index | rnafusion |
| `taxonomic/` | Simulated taxonomic reads, Kraken2 test DBs | taxprofiler |

Test data is generated by simulation scripts in `test-data/simulate-*.py` and
`test-data/download-yeast-reference.sh`.

### ARM/Rosetta failures

These tests fail because the underlying tool Docker images are x86-only and
crash or hang under Apple Silicon Rosetta emulation:

- **MACS2** (`atacseq`, `chipseq`, `cutandrun`): segfault under emulation
- **SPAdes** (`mag`): crashes under emulation; MEGAHIT works as alternative assembler
- **medaka** (`nanoseq`): model loading fails under emulation
- **Kallisto** (`rnaseq`): runs but extremely slowly (hours for small index)

These are expected to pass on x86_64 Linux (CI/cloud environments).

### Test 001: Kusako — Yeast Heat Shock RNA-seq Reanalysis

**Scenario:** Undergraduate reanalyzes published RNA-seq data (PMID 32109230, GSE135568) to check TOR pathway gene expression under heat shock. Exercises: PMC text mining → TogoID ID conversion → fetchngs → rnaseq.

**Run: 2026-03-29 — PASS**

| | Machine | Duration |
|-|---------|----------|
| Platform | Apple M4 Pro, 64 GB RAM, arm64 (Docker x86 via Rosetta) | |
| fetchngs | 2 SRA accessions, FTP download, 5.0 GB FASTQ | 51 min |
| rnaseq | STAR (index built on-the-fly) + Salmon, 2 samples | 109 min |
| **Total** | | **160 min** |

Target gene results (raw counts):

| Gene | 30°C (control) | 39°C (heat shock) | Fold change |
|------|----------------|-------------------|-------------|
| DAL5 (YJR152W) | 177 | 324 | 1.83× |
| GAP1 (YKR039W) | 293 | 418 | 1.43× |

All three nitrogen permease genes upregulated under heat shock. RO-Crate valid for both workflow runs (fetchngs: 43 entities, rnaseq: 75 entities).

**Note:** Rosetta emulation adds ~3-5× overhead. Expect ~30-40 min for rnaseq on native x86_64 Linux.

### CWL bugs fixed during testing

| Tool/Workflow | Bug | Fix |
|--------------|-----|-----|
| `tools/ensembl-vep.cwl` | `--no_cache` not recognized in VEP v115.2 | Use `--offline --dir /tmp` |
| `tools/ensembl-vep.cwl` | VEP can't parse bgzipped VCF | Decompress with `gunzip -c` before VEP |
| `tools/ensembl-vep.cwl` | Wrong flag for GTF files | Auto-detect `--gtf` vs `--gff` by extension |
| `tools/nanofilt.cwl` | NanoFilt expects uncompressed stdin | Bash wrapper detects `.gz` and pipes through `gunzip` |
| `tools/juicertools-pre.cwl` | `${VAR}` parsed as CWL JS expression | Use `$VAR` (no braces) in bash scripts |
| `tools/manta.cwl` | Same `${VAR}` CWL/bash conflict | Use `$VAR` |
| `workflows/sarek/main.cwl` | Dotproduct scatter mismatch when somatic VCFs empty | ExpressionTool returns paired `vcfs`+`ids` arrays |
| `workflows/mag/main.cwl` | Skipped scatter produces `[null]` not `null` | Change filtered input types to `Any` |
| `workflows/viralrecon/main.cwl` | `valueFrom` on scatter input evaluated per-element | Add `select_reads` ExpressionTool before scatter |
| `workflows/raredisease/main.cwl` | VEP crashes without cache or GFF | Add `when:` condition to skip VEP |
| `workflows/scrnaseq/main.cwl` | cwltool crashes on `scatter` with `null` array | Use `File[]` with `default: []` instead of `File[]?` |
